# 码道应用过程记录 —— 《粒子跃迁 ENERGY DRIFT》

> 本文档如实记录华为云码道（CodeArts）代码智能体在本项目开发全程中的实际应用过程，包括关键 Prompt、代码生成、迭代重构与排错记录。配套的对话截图材料清单见同目录 `README.md`。

## 1. 项目背景

用户向码道提出的需求原文：

> "请帮我创建一个可以运行的作品。作品用途是互动小游戏，主要用户是网络加载等待，需要包含运动元素，界面风格希望是科技粒子风。完成后请启动项目供我预览。"

需求四个关键点：**互动小游戏**、**网络加载等待场景**、**运动元素**、**科技粒子风**。

## 2. 码道工作流程实录

### 2.1 需求解析与技能调用

码道识别需求匹配游戏开发场景，自动加载 **game-maker 游戏开发技能**，按其规范完成：

- **游戏类型定位**：休闲 / 反射类（躲避 + 收集），适配"等待期间随时来一局、随时退出"的短局体验
- **状态机设计**：`IDLE → PLAYING → PAUSED → GAMEOVER → IDLE` 完整闭环
- **碰撞矩阵**：玩家 × 障碍 = 游戏结束；玩家 × 能量球 = 得分 + 连击
- **场景化设计**：顶部常驻 NETWORK SYNC 进度条模拟真实加载节奏，暴露 `finishLoading()` 接口供宿主页联动

### 2.2 代码生成（第一轮）

码道一次生成约 1600 行的单文件完整工程 `index.html`，包含：

- Canvas 2D 渲染管线：背景渐变、透视网格、三层视差星流、中央能量环
- 粒子系统：引擎拖尾、收集爆发、撞击爆炸（上限 380 粒子，防内存膨胀）
- 完整状态机与帧率无关的时间步进（dt 归一化）
- 圆形碰撞检测、连击倍率（×8 封顶）、WARP 里程碑闪光
- Web Audio API 合成音效（收集 / 撞击 / 开始 / 跃迁），M 键静音
- localStorage 最佳纪录持久化
- 桌面键鼠 + 移动端触摸（Pointer Events）双操控
- 切后台自动暂停、ESC 暂停、响应式布局

### 2.3 自动化验证（Chromium 无头实测）

码道使用 Puppeteer 驱动 Chromium 对生成的游戏进行真实运行验证，而非仅靠人工目测：

| 验证项 | 方法 | 结果 |
|--------|------|------|
| 状态闭环 | 点击开始 → 扫动 → 等待结束 → 重玩，逐帧读取 `phase` | 通过 |
| 得分/连击/最佳分 | 鼠标正弦扫动 20 秒，读取 score/best/combo | 通过（实测得分与 BEST 更新） |
| 暂停/恢复 | ESC 触发、visibilitychange 触发 | 通过 |
| `finishLoading()` | 调用后读取进度条与状态文字 | 通过（100% / SYNC COMPLETE / 变绿） |
| 移动端 390×844 | isMobile 视口实测布局与触控 | 通过（无横向溢出） |
| Console 错误 / 失败请求 | 监听 pageerror / requestfailed | 无 |

### 2.4 排错与修复记录

自动化验证与截图评审发现 2 处问题，均由码道在同会话内定位并修复：

1. **游戏结束页连击徽标残留**：GAMEOVER 后顶部 COMBO 徽标仍显示。修复：`gameOver()` 中同步隐藏徽标并清空场上实体，结束面板视觉更聚焦。
2. **favicon 404**：无 favicon 导致控制台报错。修复：改为内联 SVG data URI，零额外请求。

### 2.5 视觉与体验迭代（重构）

码道对截图进行视觉评审后主动发起一轮增强：

- **粒子氛围增强**：新增漂浮光尘层（闪烁光点）、纵向数据流线（渐变拖尾）、底部能量光带，强化"科技粒子风"主题
- **生成密度自适应**：障碍/能量球生成间隔按屏幕宽度缩放（`gapScale`），宽屏更饱满、窄屏更从容
- **移动端 HUD 重构**：由 flex-wrap 改为 Grid 两行布局（第一行 logo + 计分，第二行全宽进度条），实测无重叠、无溢出
- **待机画面优化**：IDLE 态不再绘制飞船，开始面板更干净

### 2.6 提交包生成

码道按提交要求表格自动生成完整提交结构：ppt（作品介绍）、project（可复现源码）、video（自动录制的功能演示视频）、codearts_proof（本记录）、readme（说明文档 + 一键安装/启动脚本）。
